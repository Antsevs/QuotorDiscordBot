# javaQuotorDiscordBot

A Discord bot built with Java that automatically posts daily quotes to your server. Users can submit their own custom quotes, which are queued and shared with the community. Quotes are retrieved from user submissions or from an online API as a fallback.

## Features

- **Daily Quote Posting**: Automatically posts a quote of the day to designated channels
- **User Quote Submissions**: Community members can submit custom quotes to be featured
- **Smart Fallback**: Uses queued user quotes first, then falls back to the [ZenQuotes API](https://zenquotes.io/)
- **Guild-Specific Commands**: Registers slash commands for each server the bot joins
- **Secure Configuration**: Uses environment variables to manage sensitive tokens
- **Multi-Server Support**: Works across multiple Discord servers simultaneously

## Prerequisites

- **Java 11+** (configured in pom.xml)
- **Maven 3.6+** for dependency management
- **Discord Bot Token** (obtained from [Discord Developer Portal](https://discord.com/developers/applications))

## Installation

1. **Clone or download the project**
   ```bash
   git clone <repository-url>
   cd javaQuotorDiscordBot
   ```

2. **Set up your Discord Bot**
   - Go to [Discord Developer Portal](https://discord.com/developers/applications)
   - Create a new application
   - Create a bot user for your application
   - Copy the bot token and save it securely

3. **Configure Environment Variables**
   - Set the `DISCORD_TOKEN` environment variable with your bot token
   - On Windows: `setx DISCORD_TOKEN "your_token_here"`
   - On Linux/macOS: `export DISCORD_TOKEN="your_token_here"`

4. **Build the Project**
   ```bash
   mvn clean package
   ```

## Usage

### Starting the Bot

Run the main class after building:

```bash
java -cp target/javaQuotorDiscordBot-0.0.1-SNAPSHOT-jar-with-dependencies.jar javaQuotorDiscordBot.Bot
```

Alternatively, if an executable JAR is configured, run:
```bash
java -jar target/javaQuotorDiscordBot-0.0.1-SNAPSHOT.jar
```

### Bot Status

Once running, the bot will:
- Log "The bot is ready" when successfully connected
- Display the number of queued user quotes
- Register slash commands for each connected guild
- Post daily quotes on a scheduled interval

## Key Components

### Bot.java
- Main entry point for the application
- Registers Discord slash commands
- Schedules daily quote postings
- Manages bot status and ready events

### QuoteService.java
- Retrieves quotes from queued user submissions
- Falls back to ZenQuotes API for daily and random quotes
- Handles HTTP requests with configurable timeouts

### QuoteManager.java
- Stores and retrieves user-submitted quotes
- Manages the queue of pending quotes

### ConfigManager.java
- Validates required configuration (Discord token)
- Retrieves secure configuration from environment variables

### interactionEventListener.java
- Listens for slash command interactions
- Processes user commands and submissions

## Troubleshooting

### Bot not connecting
- Verify your Discord token is correct
- Ensure `DISCORD_TOKEN` environment variable is set
- Check your bot has proper permissions in the Discord Developer Portal

### Quote API errors
- The bot will retry if the ZenQuotes API is temporarily unavailable
- User-queued quotes will be used as fallback

### Missing quotes
- Ensure no user quotes are queued, or add quotes via the bot's commands
- Check network connectivity for API calls
